# Picature

Python / Pygameで制作している、マウスで線を描いて攻略する2Dアクションゲームです。
ゲームのプログラムを自作しています。このリポジトリでは、実装内容を閲覧できるようソースコードとCSV形式のステージデータを公開しています。

> **公開範囲について**：画像・フォントなどの外部素材は再配布条件を未確認のため含めていません。このリポジトリをダウンロードしただけではゲームは起動できません。ソースコード閲覧用の公開版です。

## ゲームの特徴

- **描いた線を足場にする**：マウスで描いた線から衝突判定用のマスクを生成し、プレイヤーが線に乗れるようにしています。
- **描いた軌跡に沿ったダッシュ**：プレイヤーに重なる線を描くと、その軌跡に沿って移動します。
- **線の組み合わせによる魔法**：3本の線の長さの組み合わせを判定し、特定の組み合わせで弾を生成します。
- **敵ごとの行動**：共通の敵クラスを基に、敵の種類ごとに探索・移動・攻撃などの処理を実装しています。
- **ステージ制作ツール**：ステージデータをCSVとして保存するエディターを用意しています。

## 操作

| 操作 | 入力 |
| --- | --- |
| タイトルの選択 / 決定 | W・S / Space |
| 左右移動 | A・D |
| ジャンプ | Space |
| 線を描く | マウス左ボタンを押しながらドラッグし、離して確定 |
| 終了 | Esc |

## 開発環境・起動方法

Python 3.11系 / Pygame 2.6.1を使用したプロジェクトです。
以下は必要な素材を別途配置した開発環境向けの手順です。公開版には`assets/`が含まれないため、この手順だけでは起動しません。

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

プロジェクトのルートで実行してください。起動時はフルスクリーンになります。
素材がある環境では、同じPython環境で`stage_maker.py`を実行するとステージエディターを起動できます。
